# Black Hole Brand Design System

## Color Palette

### Primary Colors

#### Space Black `#0A0A0C`
Màu chủ đạo. Đại diện cho sự bí ẩn, quyền lực, bảo mật và nền tảng công nghệ vững chắc.

#### Singularity Purple `#6C5CE7`
Màu tím neon. Đại diện cho sự sáng tạo, tư duy đột phá và mảng Publishing.

#### Blackhole Cyan `#00CEC9`
Màu xanh ngọc công nghệ. Đại diện cho Fintech, dòng tiền, sự minh bạch và tốc độ.

---

### Neutral Colors

- **Deep Gray** `#15151A` - Background surfaces
- **Nebula Gray** `#2A2A33` - Borders and dividers
- **Lunar Silver** `#D8D8E0` - Secondary text
- **Pure White** `#FFFFFF` - Primary text

## CSS Variables

Sử dụng CSS variables trong code:

```css
/* Primary colors */
var(--color-space-black)
var(--color-singularity-purple)
var(--color-blackhole-cyan)

/* Semantic colors */
var(--color-primary)        /* Purple */
var(--color-secondary)      /* Cyan */
var(--color-background)     /* Space Black */
var(--color-text-primary)   /* White */
```

## Utility Classes

```html
<!-- Background -->
<div class="bg-singularity-purple">...</div>
<div class="bg-blackhole-cyan">...</div>

<!-- Text -->
<p class="text-singularity-purple">...</p>
<p class="text-lunar-silver">...</p>

<!-- Gradients -->
<div class="bg-gradient-primary">Purple to Cyan</div>
```

---

## Usage Guidelines

1. **Primary Actions**: Use Singularity Purple (#6C5CE7)
2. **Secondary Actions**: Use Blackhole Cyan (#00CEC9)
3. **Backgrounds**: Space Black (#0A0A0C) or Deep Gray (#15151A)
4. **Text on Dark**: Pure White (#FFFFFF) or Lunar Silver (#D8D8E0)
5. **Borders**: Nebula Gray (#2A2A33)
